# Implementation briefs

One brief per hi-fi flow row (`<surface>-row-<nn>-<slug>.md`, e.g. `attendant-row-02-record-a-sale.md`), written by frontend-engineer with the `implementation-brief` skill **before** any UI work order's builder is dispatched. The EM checks it against the board row and the decision note, and links it from the work order's Inputs.

A brief is the contract for fidelity review: the design-fidelity check and the code-reviewer compare the build against it.
