# WHR-111 review evidence test index

All cases in `review-evidence.test.ts` run service/HTTP paths against PostgreSQL in an isolated migrated schema, with retained decoded image bytes and actual persisted deployment approvals. Historical fixture assembly is explicit in `review-evidence-fixture.ts`; triggers are restored before calling application code. No provider, staging or production endpoints are used.

The common denial assertion snapshots purchases, accepted/candidate revisions, sync eligibility, correction proposals, holds, capture blocks, decisions, evaluations and purchase audit events. The common success assertion checks unchanged original facts/card linkage, at most one accepted revision, one decision/evaluation, identical replay, and database rejection of evaluation update/deletion. Cases with multiple intentional decisions assert their expected count separately.
